# Independent backend acceptance matrix

Audit date 2026-11-24. **COMPLETE** means the scoped software requirement passed the listed verification. **PARTIAL** means a supported implementation exists with a material remaining gap. **MISSING** means the requested behavior has no implementation. **BLOCKED** means a required environment or observation was unavailable.

| 2 | Event details | COMPLETE | Catalog lookup, bounded legacy Loki lookup, related IDs, opt-in admin raw masking and payload status. | Native Loki pagination and OSPF reference equality, PostgreSQL detail and 404, analyst raw denial. | Lab payload retention pending. | Event detail and missing payload contract available. |
